# Permintaan skill dari agen

Agen menulis permintaan skill di sini saat butuh kemampuan atau panduan yang belum ada. Hanya pemilik yang memutuskan skill mana yang dibuat atau diubah. Agen tidak membuat skill sendiri.

Format per entri:
- [tgl] agen · kebutuhan · alasan (contoh kasus dari hari itu) · dampak kalau tidak ada · status (baru / disetujui / ditolak)

- [2026-10-20] Layar · plugin "Social Media Skills" (hook-writer, short-form-video-script, storyboarding) · untuk hook 0–2 detik Reels dan variasi format; disarankan pemilik di agenda dadakan · dampak kalau tidak ada: variasi format bergantung pada template manual · status: baru, menunggu pemilik.
- [2026-10-20] Hope · plugin Windsor.ai (membaca reach dan saves Instagram) · ig-insights 19 dan 20 Okt belum ada, dan workflow tidak mencatat run hari ini · dampak kalau tidak ada: evaluasi performa tetap "belum tersedia" · status: baru, menunggu pemilik.
