# Backlog ide

Dikelola Kompas. Format: `- [siap|riset|terpakai] <cat> · <judul kerja> — <angle> (sumber awal: <link>)`
`siap` = sumber awal sudah ketemu dan dibuka. `riset` = masih perlu dicari.
**Urutan (permintaan pemilik 2026-10-21): FIFO.** Ide inbox diproses sesuai urutan masuk. Di antara ide backlog `[siap]` yang lolos aturan variasi, ambil yang paling lama masuk dulu. Psikologi berikutnya (Spotlight effect sudah jadi draf 26 Okt): Dunning-Kruger (19 Okt) → Kitty Genovese (21 Okt). Terpakai 27 Okt: Great Pacific Garbage Patch (utama), MSG (cadangan).
